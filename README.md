# My-first-project-

GoodNotesの資料をGoogle Drive上で自動分類・仕分けするGoogle Apps Scriptです。

## できること

- Google Drive内の「未整理」フォルダに入れたGoodNotes資料（PDF/画像）を、Gemini APIで内容を解析して科目・分野ごとに自動分類
- 「未整理」フォルダはサブフォルダも含めて再帰的に探索するため、GoodNotesの自動バックアップ機能がフォルダ構造付きで書き出しても問題なく拾える（処理後、空になったサブフォルダは自動で削除）
- 分類結果に応じて科目別フォルダを自動作成し、ファイルを移動
- 時間主導型トリガーで定期実行（デフォルト3時間ごと）
- 実行結果とカテゴリ一覧をスプレッドシートにログとして記録
- AIの判定に自信が持てない場合、または既存カテゴリと表記ゆれで重複しそうな場合は自動で振り分けず「要確認」フォルダに避難させ、メールで通知（定期実行中は確認ダイアログを出せないため）。メニューの「要確認ファイルを仕分けする」から1件ずつ保存先を決められる

## できないこと（制約）

Google NotebookLMには2026年時点で公開APIが提供されていないため、ノートブックの自動作成・自動でのソース追加はできません。
このスクリプトは代わりに「カテゴリ一覧」シートにNotebookLM連携が必要な科目フォルダを記録するので、そこから**手動で**NotebookLMのノートブックを作成し、「ソースを追加 > Google Drive」で対応するフォルダを指定してください。一度フォルダをソースとして追加すれば、以降そのフォルダに増えるファイルはNotebookLM側の同期機能で反映されます。

## セットアップ手順

1. 新しいGoogleスプレッドシートを作成する（これがログ表示・設定用の画面になります）。
2. 「拡張機能 > Apps Script」を開き、コードを貼り付ける。方法は2通りあり、どちらか一方だけを使う。
   - **1ファイル版（iPad等で手作業コピペするならこちらが簡単）**: `single-file/AllInOne.gs` の中身を、最初からある `コード.gs` に丸ごと貼り付けるだけ。ファイルを分ける必要はありません。
   - **6ファイル版（`clasp` を使う場合）**: `apps-script/` をルートにして `clasp push`。
3. Google Driveに「未整理」フォルダと、分類先の親フォルダ（例:「整理済み」）を作成する。
4. スプレッドシートを開き直すとメニュー「資料整理」が表示されるので、「初期設定」から以下を入力する。
   - 未整理フォルダのURLまたはID
   - 分類先の親フォルダのURLまたはID
   - Gemini APIキー（https://aistudio.google.com/apikey で取得）
5. 「今すぐ実行」で動作確認する。
6. 問題なければ「定期実行をONにする」で自動実行を有効化する。

## ファイル構成

`single-file/`（1ファイル版・コピペ用）

- `AllInOne.gs` - 下記6ファイルを1つにまとめたもの。内容は6ファイル版と同一

`apps-script/`（6ファイル版・`clasp` 用）

- `Code.gs` - スプレッドシートのカスタムメニュー定義
- `Config.gs` - 設定値の保存・読み込み（スクリプトプロパティ）
- `Classifier.gs` - Gemini APIによるファイル内容の分類
- `Organizer.gs` - 未整理フォルダのスキャンと仕分けのメイン処理
- `Triggers.gs` - 定期実行トリガーのON/OFF
- `Logging.gs` - 実行ログ・カテゴリ一覧シートへの記録
- `appsscript.json` - Apps Scriptプロジェクトのマニフェスト

## 動作確認用の最小版

`single-file/MiniTest.gs` は、仕分けの中核（Geminiで科目を判定 → フォルダを作成 → ファイルを移動）だけに絞った約55行のスクリプトです。

- スプレッドシートと紐づいていない単独のApps Scriptプロジェクトでも動きます（`SpreadsheetApp` を使わないため）
- ログ・要確認キュー・メニューはありません。結果は「実行ログ」で確認します
- 設定はファイル冒頭の3つの変数を直接書き換えます
- タブレット等で長いコードの貼り付けが途中で切れる場合の、動作確認用の入口として使います

## 単独プロジェクト版（スプレッドシート不要）

`single-file/Standalone.gs` は、スプレッドシートに紐づけずに動く約190行の完全版です。タブレットからでもセットアップできるよう、以下の点が異なります。

- `SpreadsheetApp` を一切使わないため、script.google.com で作った単独プロジェクトでそのまま動きます
- 既存カテゴリは、保存先フォルダ内のサブフォルダ名から読み取ります（カテゴリ一覧シート不要）
- 判定に自信が持てない場合・重複フォルダの疑いがある場合は「要確認」フォルダに避難させ、その一覧をメールで送ります。振り分けはDrive上でファイルを移動して行います（ダイアログ不要）
- 実行結果はメールと実行ログで確認します
- 設定はファイル冒頭の3つの変数を直接書き換えます
- 定期実行は `enableSchedule` を1度だけ手で実行してONにします

## 同じノートを書き足したとき

GoodNotesで同じノートに加筆して再バックアップすると、同じファイル名のPDFが再び「未整理」に届きます。Google Driveは同名ファイルを別物として保存するため、そのままでは科目フォルダに同名ファイルが並んでしまいます。

`Standalone.gs` の `moveInto` は、移動先に同名ファイルがあれば古い方をゴミ箱に送ってから新しい版を入れます。常に最新版だけが残り、古い版もゴミ箱から30日間は復元できます。
